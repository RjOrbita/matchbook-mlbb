Post-game workflow

Record one completed game

Complete the scoreboard from your screenshot, then save. Required fields are marked with an asterisk.

Recommended order: fill the match details → draft → player scoreboard → final items. The screenshot is a visual reference only; it is not uploaded or saved.

1. Match details

Everything needed to locate this game later.

2. Draft: picks and bans

Enter picks in order. Bans are optional for the first version.

3. Team objectives

Use zero for an objective not taken. First Blood is recorded as yes/no.

4. Player scoreboard and final builds

Items can be entered as a comma-separated final build, in slot order.

SidePlayer *Hero *RoleKDAKDAGoldDamage dealtDamage takenTurret dmg.Obj. dmg.TF part. %Final item build

Extra values are optional—record them whenever the screenshot or replay makes them available. The system uses K/D/A, hero, and winner for the primary leaderboards.
